# ProcesamientoAsincrono

Ejercicio original revisado el 3 de noviembre de 2026.

Requiere JDK 17 o superior y Maven. Abrir en NetBeans la carpeta que contiene `pom.xml`.

```sh
mvn clean test
mvn exec:java
```

Clase principal: `com.mycompany.procesamientoasincrono.ProcesamientoAsincrono`.

El orden de los dos retiros puede variar. Uno se acepta y el otro informa fondos insuficientes; el saldo final es 300 o 500. coneccionDB y prueba2 son esqueletos conservados del ejercicio original.
